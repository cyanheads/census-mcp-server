# 0.1.10 — 2026-06-12

## Added

- **`census_search_variables`**: `truncated`, `shown`, and `cap` output fields plus a `ctx.enrich.truncated()` signal when `total_matches` exceeds the limit — the result now discloses how many variables were cut off and how to widen the query.
- **`scripts/clean-mcpb.ts`**: post-pack MCPB cleaner wired into the `bundle` script — runs the official `mcpb clean` prune, then strips dependency-shipped agent docs (`node_modules/**/skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach.
- **`lint:packaging`**: bundle-content and identity checks — `.mcpbignore` anchoring guard, critical-runtime-path protection, post-bundle agent-doc assertion, and `createApp()` `name`/`title` vs. unscoped package-name verification.
- **`check-framework-antipatterns`**: `coerce-boolean-env-flag` rule flags `z.coerce.boolean()` on env flags (`Boolean("false") === true` makes them un-disableable) and recommends `z.stringbool()`; comment lines are skipped so docs naming the pattern don't trip it.

## Changed

- **`createApp()`**: sets explicit `name` and `title` of `census-mcp-server` so the hyphenated repo name is the display identity across clients and registries.
- **`census_query_data`** and **`census_compare_geographies`**: `variable_not_found` error code changed from `ValidationError` to `NotFound` — an unknown variable code is a missing resource, not malformed input.
- **`census_resolve_geography`**: empty or whitespace-only `name` now throws `validationError()` instead of the `no_match` (NotFound) contract reason — a blank name is invalid input, not an unmatched place.
- **`.mcpbignore`**: root dev-dir patterns (`skills/`, `.agents/`, `.claude/`) anchored with a leading `/` so they no longer also strip nested runtime paths under `node_modules/`.

## Dependencies
