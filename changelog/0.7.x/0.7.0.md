# 0.7.0 — 2026-10-28

## Added

- **`skill://census-guide/SKILL.md` resource**: `resources/list` now lists it and `resources/templates/list` lists the `skill://{+path}` template, served through mcp-ts-core 0.13.18's `createApp({ skills })`. The `census-guide` skill covers choosing a dataset and vintage, finding variable codes for lay concepts (rent burden, poverty rate), reaching geographies `census_resolve_geography` cannot name (New England towns, tribal areas), and reading ACS margins of error before ranking places, comparing a tract with its county, or comparing years. It also ships in the npm package, the Docker image, and the `.mcpb`.
- **Agent Plugins root `plugin.json` and `mcp.json`** ([cyanheads/mcp-ts-core#426](https://github.com/cyanheads/mcp-ts-core/issues/426), mcp-ts-core 0.13.18): one stdio entry running `npx -y @cyanheads/census-mcp-server`.

## Changed

- **Enrichment trailer strings in `content[]` render as code spans** ([cyanheads/mcp-ts-core#785](https://github.com/cyanheads/mcp-ts-core/issues/785), mcp-ts-core 0.13.18): the `census_search_variables` query echo and string lines such as `source` no longer carry backslash escapes when copied. `structuredContent` is unchanged.
- **`.mcpbignore` is root-anchored and covers source, tests, docs, caches, and plugin manifests** ([cyanheads/mcp-ts-core#508](https://github.com/cyanheads/mcp-ts-core/issues/508)), and the bundle cleaner drops the framework's build-only files ([cyanheads/mcp-ts-core#791](https://github.com/cyanheads/mcp-ts-core/issues/791)), both mcp-ts-core 0.13.18.
- **The bundle cleaner and packaging check strip agent docs only at a dependency's package root**, so the `.mcpb` keeps the MCP SDK 2.4 `dist/ext/skills/` runtime modules the skill server imports ([cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794), open upstream; patched locally in `scripts/clean-mcpb.ts` and `scripts/lint-packaging.ts`).
- **Dockerfile** copies `skills/` into the image and creates writable `.cache` and `.mirror` directories for the runtime user.
- **Development tooling** syncs mcp-ts-core 0.13.18's scripts and framework skills (new `add-skill`), revises the issue templates, and lowers `bunfig.toml` `minimumReleaseAge` from 3 days to 1.
- **README Getting started** condenses to the hosted `claude mcp add` command, a local `npx` command, and one generic client config; Docker and source-build detail moves under Running the server.
- **CLAUDE.md and AGENTS.md** correct the config pattern: handlers read `getDiscoveryConfig()` and only the Census API service calls `getServerConfig()`, so keyless tools run without `CENSUS_API_KEY`. The Skills, Bundling, and checklist sections gain the published-skill and Agent Plugins guidance.
- **`docs/design.md` Known Limitations** corrects two lines: a small-geography ACS1 query fails with `no_data` and a hint to `acs/acs5`, and a 2020 ACS1 query fails with `year_not_available` before any request.

## Fixed

- **Hosted HTTP no longer grows the heap per request**: each request's abort controller is released when its response ends ([cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786), mcp-ts-core 0.13.17). 0.13.16, which 0.6.3 ran, retained about 71 KiB per request, so sustained traffic grew the heap.
