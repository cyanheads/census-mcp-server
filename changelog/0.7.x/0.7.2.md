# 0.7.2 — 2026-11-03

## Added

- **Comparison pagination and scope ranks** — `census_compare_geographies` accepts `offset`; filtered rows retain subset `rank` and fetched-scope `scope_rank`, with `scopeCount` naming that scope's size. ([#84](https://github.com/cyanheads/census-mcp-server/issues/84))
- **Discovery pagination** — `census_search_variables` and `census_list_predicate_values` accept `offset` after matching and ordering, with `nextOffset` only when another page exists. ([#85](https://github.com/cyanheads/census-mcp-server/issues/85))
- **Predicate geography scope** — live `census_list_predicate_values` accepts and echoes `geography_level` for levels enumerable without concrete parents; dictionary responses explain that they do not validate publication at a supplied level. ([#81](https://github.com/cyanheads/census-mcp-server/issues/81))

## Changed

- **Documentation and `census-guide` 1.0 → 1.1** — document paging, ranking, discovery scope, request budgets, and product-specific ACS publication rules with variable rediscovery when changing datasets.

## Fixed

- **Query continuation** — `census_query_data` reports `truncated: false` on final and past-end pages; `nextOffset` appears only when rows remain, while range and empty-page guidance stays available. ([#82](https://github.com/cyanheads/census-mcp-server/issues/82))
- **Comparison ties** — equal numeric estimates share competition ranks (`1, 2, 2, 4`) before paging, ordered by GEOID; page boundaries inside ties receive a notice. ([#83](https://github.com/cyanheads/census-mcp-server/issues/83))
- **Keyed-call deadlines** — metadata, data, retries, body reads, and optional probes share a 50-second upstream budget; data retains its 40-second ceiling within it. Exhausted transport failures return actionable reasons and recovery, preserving caller cancellation. ([#79](https://github.com/cyanheads/census-mcp-server/issues/79))
- **Missing-geography recovery** — both data tools explain applicable ACS coverage rules as possible causes alongside code and predicate checks; broader-coverage suggestions require rediscovering variables, and profile fallbacks disclose loss of comparison history. ([#87](https://github.com/cyanheads/census-mcp-server/issues/87))
