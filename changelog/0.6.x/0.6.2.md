# 0.6.2 — 2026-10-13

## Added

- **`dec/ddhcb` dataset** (#54): the 2020 Detailed DHC-B. Its `POPGROUP` value check unions `T04001` and `T04002`, so `census_list_predicate_values` lists all 2,996 groups.
- **Sibling-table hints on split group tables** (#68): on `dec/ddhca` `T02001`–`T02003` and `dec/ddhcb` `T03001`–`T03004` and `T04001`–`T04002`, a `no_data` hint and a result notice name the sibling tables that publish the group, instead of blaming the `POPGROUP` value.
- **`census_search_variables` finds variables and tables by code** (#63): `B19013`, `P1`, `GEO_ID`, and `NAICS2017` return that variable, or the table's variables in code order, ahead of keyword matches. A letter-only code leads only when typed in its own uppercase. A code-shaped miss gets a notice naming the sibling dataset, the attribute column, or that nothing was found. A table cut at `limit` names the last code shown.
- **`variable_not_found` names the sibling dataset that holds the code** (#65) on `census_get_variable`, `census_query_data`, and `census_compare_geographies` (`S1701_C03_001E` asked of `acs/acs5` points at `acs/acs5/subject`).
- **NYC borough names resolve to their counties** (#66): "Brooklyn, NY", "The Bronx", and "Queens borough" return the county with a notice; at `place` level the hint names the county.
- **Declared error reasons** (#62): `upstream_error` on `census_get_variable`, `census_search_variables`, and `census_list_geographies`; `variables_unavailable` on `census_list_predicate_values` (#54).

## Changed

- **`census_list_geographies`** (#62): `totalLevels` counts distinct levels (`acs/acs5` 2024: 65 → 43, matching the data tools), and `year_not_available` names the years the dataset serves.
- **Error messages and recovery hints no longer repeat each other** (#62), across all tools.
- **`census_list_predicate_values`** (#54): the publication check stops at a 20 s deadline, a cancelled call stays an error, and `no_values` offers the `within_naics` hint only when that scope was applied.
## Fixed

- **Comparison-profile significance columns** (#59): `CP03_2024to2019_062SS` and the like on `acs/acs5/cprofile` and `acs/acs1/cprofile` were uppercased before the request and rejected upstream. `census_query_data` and `census_compare_geographies` now accept them in any case, `sort_by` included, and key rows in the dataset's spelling.
- **`census_get_variable` survives a `groups.json` failure** (#60): on an error, a 20 s hang, or a body with no `groups` list, variables return without `universe` plus a retryable notice. A cancelled attribute fetch stays an error.
- **`attribute_type` is upper-snake on every vintage** (#61): `Annotation` → `ANNOTATION` on 5-year ACS through 2010, 1-year ACS through 2011, and `dec/pl` 2010.
- **"Bronx, NY" and "Queens, NY" at `place` / `economic place`** (#69) no longer return Bronxville or Queensbury; they return `no_match`, naming the county.
