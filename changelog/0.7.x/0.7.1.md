# 0.7.1 — 2026-10-29

## Changed

- **`census_query_data` documents comma-separated `geography_fips` lists** (`"06,53"`, or `"033,061"` with `parent_fips`), and its `notice` names each listed code no row came back for (#74).
- **Notices that quote caller or upstream text render literally in `content[]`** on `census_search_variables`, `census_list_datasets`, `census_list_predicate_values`, `census_compare_geographies`, and `census_query_data`; `structuredContent.notice` stays raw (#72).
- **`census_list_predicate_values` declares `missing_api_key`.** A dictionary list (`NAICS*`, `POPGROUP`) still answers with no working key, unchecked, and its notice names `CENSUS_API_KEY` rather than saying the check "was not possible on this call" (#75).
- **`parent_required` also names a supplied parent to drop** (`unacceptedParents`) when the closest hierarchy does not take it, and the `parent_not_accepted` hint on `census_compare_geographies` reads "the comparison needs no other scope" (#70).
- **`instructions`, README, `docs/design.md`, CLAUDE.md, AGENTS.md, `server.json`, `manifest.json`, and the plugin manifests** name `census_list_predicate_values` among the tools that need the key and describe the list form and the multi-hierarchy check.

## Fixed

- **A level `geography.json` lists under several hierarchies is checked against every entry** (#70): `new england city and town area`, `new england city and town area (or part)`, `american indian area/alaska native area/hawaiian home land (or part)`, and `state (or part)` run when any entry accepts the call, where they failed `parent_required` against the first entry. When none accepts, the error describes the entry nearest to accepting it.
- **A `"*"` parent a level's hierarchy cannot wildcard is refused before the request** (#77): `parent_fips` or `within` as `"*"` where the entry's `wildcard` list omits `state`, and `county_fips` or `within_county` as `"*"` where it omits `county`, now fail `parent_required` with a hint to send one concrete code. The Census API answered each with HTTP 400.
- **An unset, blank, unsubstituted `${user_config.CENSUS_API_KEY}`, or rejected key fails as `missing_api_key` with its recovery hint** (#75) on `census_query_data`, `census_compare_geographies`, and a live-route `census_list_predicate_values`, replacing a bare `ConfigurationError` and a retried `upstream_error`. An unset key fails before any keyed request, a rejected one after one; the keyless tools and the `CENSUS_DEFAULT_YEAR` check are unchanged.
- **Data requests settle within 40 s across attempts** (#78): a hung endpoint now fails as a retryable `upstream_error` with `deadlineMs`, `elapsedMs`, `retryAttempts`, and a recovery hint, where `queryData` and `fetchPredicateValues` held the call about 68 s.
