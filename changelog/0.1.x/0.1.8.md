# 0.1.8 — 2026-06-02

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.16` → `^0.9.21` — adopts three framework fixes: per-request log context (HTTP transport now carries fresh request/trace/span IDs instead of frozen boot context); `fetchWithTimeout` strips query-string secrets (e.g. `?api_key=`) from error messages and logs; `withRetry` fails fast on non-retryable errors and `ctx.fail` auto-populates the `retryable` flag.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.9.16` → `^0.9.21`
- `vitest` `^4.1.7` → `^4.1.8`
