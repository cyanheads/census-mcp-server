# 0.8.0 — 2026-11-15

Breaking:

- `rows[].variables[code].label` is removed from `census_query_data` and `census_compare_geographies`; each variable's label is stated once in the new top-level `variable_labels`.
- In CT, ME, MA, MI, MN, NH, NJ, NY, PA, RI, VT, and WI, an auto-detected name that 0.7.2 answered with a CDP or a containing place can now fail `ambiguous_name` when two governing towns or townships share the name ("Hamilton, NJ", "Springfield, NJ", "Rangeley, ME"). `geography_type: "place"` still reaches the CDP.
- Yearless calls now default to 2025 (`acs/acs1`, `acs/acs1/profile`, `acs/acs1/subject`, `acs/acs1/cprofile`, `acs/acs1/spp`, `acs/acsse`) or 2024 (`nonemp`). Codes the old default year published and the new one does not now fail `variable_not_found`: `acs/acs1/cprofile` `CP*_2020_*` and `acs/acs1` `B15003_024E`/`B15003_025E`. Pass `year: 2024` to keep them.

## Added

- **`variable_labels`** — top-level code → label map on `census_query_data` and `census_compare_geographies`, repeated on every page and rendered as one legend ahead of the rows in `content[]`; annotation and flag columns (`B19013_001EA`, `EMP_F`) have no entry. See the breaking note above. ([#93](https://github.com/cyanheads/census-mcp-server/issues/93))
- **`group` on `census_query_data`** — one table ID returns every column of that table in one call, outside the 49-code limit; `variables` becomes optional. Unsupported on datasets with filter or record dimensions (`group_not_supported`). The group deadline hint also names the 50-second call budget. ([#88](https://github.com/cyanheads/census-mcp-server/issues/88))
- **County subdivisions in `census_resolve_geography`** — `geography_type: "county subdivision"` resolves in every state and returns `county_subdivision_fips`; addresses return it too. In the twelve states above it is auto-detected after place and county. The `ambiguous_name` hint for two same-county subdivisions names the full listed name, and the namesake check degrades on any upstream failure. See the breaking note above. ([#90](https://github.com/cyanheads/census-mcp-server/issues/90))
- **Connecticut's pre-2022 counties** — "Fairfield County, CT" resolves to county `001` (the eight counties are `001`–`015`) with a notice, since every vintage through 2021 publishes them. ([#86](https://github.com/cyanheads/census-mcp-server/issues/86))
- **2025 ACS 1-year vintages and `nonemp` 2024** — added to `DATASET_AVAILABLE_YEARS` for the six ACS 1-year datasets above and `nonemp`. See the breaking note above. ([#91](https://github.com/cyanheads/census-mcp-server/issues/91))
- **`geoinfo` dataset (2020–2025)** — land and water area and internal points at every level, the denominator for density; the catalog carries the recipe, and the `census-guide` density recipe notes that tract counts for 2019 or earlier sit on 2010 tracts, so a GEOID join drops redrawn tracts, and that a water-only tract has `AREALAND_SQMI` 0. ([#92](https://github.com/cyanheads/census-mcp-server/issues/92))
- **Boundary-vintage hints** — `no_data` and the unmatched-code notice on both data tools name the earlier tracts (2010; 2000 for `acs/acs5` 2009 and `dec/pl` 2000) or the Connecticut county scheme a vintage publishes, and a resolved tract carries a notice that it is a 2020 tract. ([#94](https://github.com/cyanheads/census-mcp-server/issues/94))

## Changed

- **ACS 1-year 2025 renumbering** — 127 lines in 14 tables were renumbered, so a yearless `B15003_022E` now means "Professional school degree". Pin `year` to keep the old meaning.
- **`resolution_unavailable`** — also covers TIGERweb and geocoder 5xx, network failures, timeouts, and the 50-second geography call budget, and always carries `ServiceUnavailable`.
- **Geocoder 400** — returns reason `address_rejected` (a validation error); 0.7.2 returned -32602 "Fetch failed". ([#94](https://github.com/cyanheads/census-mcp-server/issues/94))
- **Geography budget** — one resolution's TIGERweb and geocoder requests share a 50-second budget. ([#94](https://github.com/cyanheads/census-mcp-server/issues/94))
- **`census-guide` skill 1.1 → 1.2** — adds towns and townships, a whole table, and density.

## Fixed

- **`content[]` numbers** were rounded to 3 decimals in the host locale; they now carry full digits with en-US separators.
- **`__proto__, NY`** crashed with -32603.
- **A `constructor` or `__proto__` state suffix** was misread.
- **A county `no_match` scoped by `county_fips`** read "in county 033"; it now reads `No county named "X" has code 033 in WA.`
